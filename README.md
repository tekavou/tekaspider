# tekaspider

## BOM:

- Any Halloween decorative spider
- A microcontroller. I used a Seeed Studio XIAO but an ESP32 or Arduino will also work out of the box
- A 5V Addressable LED strip (I used a 5 wire one)
- A 5V power supply

## Instructions:

1. Connect your red wire to the 5V in, the black wire to the Ground (GND) and the green wire to any data port. I used D5 (adjust in the code if you use anything else). Solder everything in place or use Dupont cables if your microcontroller has input pins

2. Attach the LED strip to the spider (hot glue works)

3. Connect to 5V to the extra red/black wire

4. Using Arduino IDE, copy the code to your microcontroller 

5. Power it up and hang from a high place
